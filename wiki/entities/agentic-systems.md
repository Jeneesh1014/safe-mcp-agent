# Agentic Systems

In the context of this document, an agentic system refers to a programmatic entity that interacts with customers. In the ACME Corp support runbook, these systems are used to send automated requests for information or actions.

Key Facts:
* The systems must be authorized through internal integrations before they can access customer data.
* Any instructions provided in customer-provided text fields must be flagged to the security team immediately.
