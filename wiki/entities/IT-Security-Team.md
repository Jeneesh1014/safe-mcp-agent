# Information Technology Security

ACME Corp's IT security team is responsible for maintaining the company's information systems. This includes implementing access controls, monitoring system activity, and responding to security incidents.

# Roles and Responsibilities

- **IT Security Team**: Responsible for implementing and enforcing security policies, conducting vulnerability assessments, and providing incident response services.
- **Employee Responsibility**: Employees are responsible for reporting security incidents, using authorized systems, and following security guidelines.

# Security Incident Reporting

Security incidents must be reported to the IT security team within one hour of discovery. This includes suspected data breaches, unauthorised access, and phishing attacks.

# Compliance with Regulations

ACME Corp complies with relevant data protection regulations, including GDPR and CCPA. Employees are expected to familiarize themselves with these regulations and adhere to them in their work.

# Security Training

Regular security training is provided to employees to educate them on the latest security threats and best practices.

# Reporting Security Incidents

To report a security incident, contact the IT security team at [security@acme-corp.example.com](mailto:security@acme-corp.example.com).
