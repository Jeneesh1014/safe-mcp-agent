# Access Control
Access control refers to the mechanisms and procedures used to regulate access to resources, information, or systems within ACME Corp.

In the context of this document, access control is a critical component of ensuring the security and integrity of customer data.

For more information on access control policies in ACME Corp, refer to the [ACME Corp Information Security Policy](entities/ACME-Corp-Information-Security-Policy).
